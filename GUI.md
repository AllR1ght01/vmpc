# Desktop interface

У vmpc теперь есть собственный HTML desktop-интерфейс. Локальный сервер доступен
только на `127.0.0.1`, а страница открывается в отдельном Edge/Chrome app-окне
без вкладок и адресной строки. Интерфейс использует тот же конфиг, транспорт API,
потоковые события, контекст файлов и хранилище чатов, что и терминальная версия.

## Запуск из исходников

Из каталога `vmpc`:

```powershell
python vmpc_gui.py
```

или:

```powershell
python -m vmpc --gui
```

После установки editable-пакета:

```powershell
vmpc-gui
```

## Что уже работает

- боковая панель с сохранёнными чатами;
- новый чат и продолжение старого;
- сообщения оформлены как в современных AI-клиентах; у каждого ответа показана
  фактическая модель, использованная в этом запросе;
- потоковый ответ и остановка генерации;
- выбор модели прямо в нижней панели ввода;
- понятный выбор режима с описанием назначения (`Обычный`, `Dev`, `Short`,
  `Explain` и пользовательские режимы);
- окно настройки OpenAI/Anthropic-compatible endpoint;
- подключение файла или папки как контекста;
- сохранение диалога в тот же `~/.vmpc/chats`.

## Сборка exe

PyInstaller не добавляется в runtime-зависимости проекта. Если он установлен:

```powershell
pyinstaller --noconfirm --clean --onefile --windowed --name vmpc-gui --add-data "vmpc/web;vmpc/web" vmpc_gui.py
```

Готовый файл появится в `dist/vmpc-gui.exe`. Рядом с ним не нужен Python:
настройки и чаты по-прежнему будут храниться в профиле пользователя.
